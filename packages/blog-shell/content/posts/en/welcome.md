# Welcome to My Blog

Hello and welcome! This is my first blog post built with **Next.js 15** and **MDX**.

## About This Blog

This blog is built using modern web technologies:

- **Next.js 15** with App Router
- **TypeScript** for type safety
- **MDX** for rich content
- **TailwindCSS v4** for styling
- **Keystatic** for content management
- **Giscus** for comments

## Features

### 1. Multi-language Support

This blog supports both English and Vietnamese. You can switch between languages using the language selector.

### 2. Git-based CMS

All posts are stored as MDX files in the repository. This means:

- Version control for all content
- No external database needed
- Write posts in your favorite editor

### 3. Anonymous Comments

Comments are powered by GitHub Discussions through Giscus, providing a spam-free commenting experience.
