# Custom Events + Typed Wrapper - Module Federation Event Bus

## 🎯 Overview

Hệ thống **Event Bus** type-safe cho phép các micro-frontends giao tiếp với nhau mà không cần phụ thuộc trực tiếp. Được xây dựng với TypeScript, React Hooks và tích hợp hoàn hảo với Module Federation.

## 💡 Usage Examples

### Emitting Events

```typescript
import { useEventBus } from './hooks/useEventBus';

function MyComponent() {
  const { emit } = useEventBus();

  const handleClick = () => {
    // Emit notification
    emit('notification:show', {
      message: 'Action completed!',
      type: 'success',
      duration: 3000
    });

    // Share data with other remotes
    emit('data:share', {
      type: 'my-data-type',
      payload: { foo: 'bar' },
      source: 'my-app'
    });
  };

  return <button onClick={handleClick}>Do Something</button>;
}
```

### Listening to Events

```typescript
import { useEventListener } from './hooks/useEventBus';

function MyComponent() {
  // Listen to theme changes
  useEventListener('theme:changed', ({ theme }) => {
    console.log('Theme changed to:', theme);
    document.documentElement.classList.toggle('dark', theme === 'dark');
  });

  // Listen to data from other remotes
  useEventListener('data:share', ({ type, payload, source }) => {
    if (type === 'typescript-generated') {
      console.log('Code generated by:', source);
      console.log('Payload:', payload);
    }
  });

  return <div>My Component</div>;
}
```

## 📋 Available Events

| Event Type | Payload | Purpose |
|------------|---------|---------|
| `theme:changed` | `{ theme: 'light' \| 'dark' }` | Sync theme across remotes |
| `notification:show` | `{ message: string, type: 'success'\|'error'\|'warning'\|'info', duration?: number }` | Display notifications |
| `data:share` | `{ type: string, payload: unknown, source: string }` | Share data between remotes |
| `user:action` | `{ action: string, data?: unknown }` | Track user interactions |
| `remote:mounted` | `{ remoteName: string }` | Remote loaded |
| `remote:unmounted` | `{ remoteName: string }` | Remote unloaded |
| `navigation:change` | `{ path: string, source: string }` | Navigate between remotes |

## 🎨 Features

### ✅ Type Safety
```typescript
// ✅ Type-safe - TypeScript knows the payload structure
emit('notification:show', {
  message: 'Hello',
  type: 'success', // Must be 'success' | 'error' | 'warning' | 'info'
  duration: 3000
});

// ❌ Type error - unknown event
emit('unknown:event', { data: 'test' });

// ❌ Type error - wrong payload
emit('notification:show', {
  message: 'Hello',
  type: 'invalid' // Error: Type 'invalid' is not assignable
});
```

### ✅ Auto Cleanup
```typescript
// Component unmounts → listeners automatically removed
useEventListener('theme:changed', callback);
```

### ✅ Debug Mode
```typescript
// Enable in portfolio-home
eventBus.setDebugMode(true);

// Console output:

// [EventBus] Event "notification:show" emitted with payload: {...}
```
