## MVP là gì?

**MVP (Minimum Viable Product)** là phiên bản đơn giản nhất của một sản phẩm có thể được release để kiểm tra ý tưởng với user thực.

### Đặc điểm

- 🎯 Có đủ features để giải quyết problem
- 🎯 Tối thiểu hóa effort & cost
- 🎯 Dễ kiểm tra giả thuyết
- 🎯 Có thể iterate dựa trên feedback

### Ví dụ

**MVP của Uber:**
- Chỉ cho phép request ride
- Basic driver matching
- Simple payment

**Không phải MVP:**
- Rating system, filters, history, promo
- Upfront pricing, splits, scheduling

### Lợi ích

1. **Fast to market** - ship quick, learn faster
2. **Real feedback** - từ user thực, không assumption
3. **Cost effective** - tránh build features không ai dùng
4. **Reduce risk** - fail fast, iterate quick

### So sánh

| Phase | Features | Goal |
|-------|----------|------|
| **Prototype** | Basic mockup | Validate idea |
| **MVP** | Core features | Find product-market fit |
| **V1.0** | Full feature set | Market ready |

### Anti-pattern

❌ Perfecting MVP  
❌ Over-engineering  
❌ Building features không ai request  
❌ Ignoring user feedback  

### Tư duy MVP

"Done is better than perfect. Ship, learn, iterate."
